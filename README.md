# New York Foreclosure Surplus Data Project

Beginnings of a data collection project that didn't quite get off the ground due to funding issues.  
The idea was to find foreclosure sales where there was a surplus by calculating the difference between the sale price and the lien + other fees amount held on the property.
Scripts (in 01_code) showcase public (& without robots.txt limitations) data scraping, OCR implementation, and data structuring and cleaning.
